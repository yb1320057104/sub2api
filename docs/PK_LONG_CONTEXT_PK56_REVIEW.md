## 最终范围

- 保留 pk.55 的八类审计菜单：通用设置、内容审计、关键词审计、提示词审计、风险分级、自动处罚与扣费、扣款诊断、审计记录。每次显示一个面板；内容与关键词使用唯一编辑器和草稿，切换不丢失未保存修改，统一原子保存。
- 启停、分级、自动处罚、规则和刷新开关使用 Toggle；分组、扫描器和事件多选保持复选框。内容及提示词记录视图不再挂载第二份配置。
- 管理员与普通用户都可打开独立耻辱排行榜。普通用户继续访问脱敏只读榜，管理员保留手动扣款预览／确认；自动处罚设置集中在审计中心。菜单与排行榜源码交接细节和此前模拟结果保留在 `PK_AUDIT_MENUS_PK55_REVIEW.md`，不当成本版发行验收。
- GPT-6.1 Sol API 模型默认长上下文门槛改为 **原始上下文严格大于 500000 token**。等于 500000 不触发该默认模型长上下文附加费，500001 才跨越门槛。基线源码相关默认价卡为 272000，不能把口头“256k”写成代码中原来使用的精确值。
- GPT-6.1 Sol 订阅类 OAuth 账号继续保留既有模型长上下文豁免，依据实际凭据及最终发送模型判断；API Key 账号不继承订阅豁免。此处“订阅账号”指上游 OAuth 类凭据，不是本站用户是否购买订阅套餐。

默认模型长上下文倍率保持输入／缓存侧 2 倍、输出侧 1.5 倍；现有模型价卡、服务档位、分组／账号开关和独立倍率仍按原规则组合，不将整笔费用统一乘以 2。回退价卡、随包目录的 Sol 条目，以及远程目录中已启用阶梯的默认门槛同步使用 500000；管理员明确 override 的阈值或关闭仍优先，不强行开启原本关闭的阶梯。自定义区间定价、缓存转换及账号统计仍保留原始上下文语义，不能由转换后的 token 数改变选档。其他模型的门槛不随本版调整；不把模型最大输入长度或输出长度误当成加价门槛。

无新增 ID、数据库迁移或依赖，不回写历史用量／账单，不修改首字计时、审计追加费用规则或生产配置。长上下文扩展既有 PK-004；审计界面继承 PK-026/031/041/043，沿用 PK-021/027/046。PK-028 为 Kilo 桥接、PK-033 为联系方式，本版不因模型或展示关键词而扩展这两个无关保护项。
