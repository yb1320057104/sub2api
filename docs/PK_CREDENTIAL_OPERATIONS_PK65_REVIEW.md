## 用户可见行为

- 凭证运营成为统一入口，提供凭证账号、授权巡检、首次授权、登录出口、凭据历史与规则设置。原账号授权地址保留页签跳转；雷达授权巡检跳转至统一页。首次授权的分组、测智、代理池、任务历史和凭据查看权限仍然保留。
- 批量添加接受每行 `邮箱----密码` 或 `邮箱----密码----2FA密钥`，最多 200 行、2 MiB。按归一化邮箱匹配唯一现有 OpenAI OAuth 账号；缺失、歧义、重复、无效、正在授权分别报告。不隐式新建业务账号；新账号仍走首次授权。
- 从授权历史补入：在服务器内读取有效加密历史、验证账号身份并重新加密到凭证运营的独立密钥域，不经浏览器查看明文。只给尚无登录配置的账号复制凭据；已有配置、显式清除的密码/2FA、现有自动化开关不覆盖。历史墓碑、待处理提交和不完整任务仍按原历史视图过滤。
- 自动纳入默认关闭。启用后由现有活动 worker 分页纳入账号；缺材料显示待配置，不凭旧 Codex Token 推导密码或生成 Excel 授权。正常新纳管账号默认开启巡检/自动重登，停用、停调或确认封禁账号默认关闭两开关；已有开关保持。旧雷达自动重授权跳过已纳管账号，原雷达被动状态观测仍保留。
- 自动纳入开启时页面与服务端均禁止移除，提示暂停或先关闭自动纳入；关闭后移除与自动纳入的在途批次通过同一短事务锁串行复核，避免删除后立即重加并重置预算。
- 同步单次最多处理 1000 个账号，并返回续接游标；页面累计结果，支持失败后续接及游标停滞保护。后台每轮最多 200 个、20 秒，并保留正常巡检时间。
- 登录出口增加随机原生代理。每次登录从 IP 管理选择有效静态代理，整次登录、OAuth 回调兑换与对应 2FA 操作保持该出口；不修改账号业务代理绑定。池空、失效或读取失败明确失败，不降级直连。指定代理、跟随账号代理和 Mihomo 保留；远程引擎仍使用其自身出口语义。

## 后端与权限

- 批量和同步为完整管理员专用 POST，受限管理密钥不能调用；响应不缓存，输入有大小与时间限制，审计保留动作但省略整段凭证正文。
- 新旧自动重登、手动任务、Excel/SIWC 和 2FA 入队共享现有短事务锁 `70360004`，在创建时检查另一队列的同账号/邮箱活动任务。锁不跨浏览器或网络请求；原各队列唯一约束、租约、凭据快照和回调 fencing 保留。
- Excel/BPS 自动补授权候选在 `LIMIT` 前排除旧授权活跃任务，避免前排占用使后续账号饥饿；自动补授权与 429 自动轮换 2FA 还需在入队事务中复查账号与凭证运营暂停/封禁条件，防止新复制的配置绕过停用开关。显式手动操作继续沿用原权限和业务校验。
- 该互斥范围是旧账号授权和凭证运营的任务队列，不宣称 Session 导出和独立手动多授权连接都已改用同一个队列。
- 历史导入按账号及配置事务写入；不存在配置使用冲突不覆盖，现有配置的显式批量更新使用版本校验。输出和告警不包含密码、种子、令牌或加密正文。
- 迁移 `342_openai_reauth_random_proxy.sql` 只扩展登录出口检查约束，保留旧数据与默认值。回退到不认识 `random_managed` 的程序前，应先将该登录策略改回旧程序支持的策略；不删除迁移或修改旧迁移校验和。
- HA 使用原有后台启动门和唯一活动 worker。没有在 API 角色新增独立扫描器。热路径、首字、账务、分组 Ultrafast 和模型请求策略不改动。
