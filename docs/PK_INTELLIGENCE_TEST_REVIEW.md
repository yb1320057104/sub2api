管理员打开“智商测试”，配置两类提示词、模型、强度和间隔，先一键生成测试 Key，再保存开启总开关。普通用户随后看到 SVG/糖果题及分组页签，只读最近30条结果。关闭总开关隐藏普通用户入口并停止测试；管理员仍可配置。两类任务可分别关闭。

一键更新采用用户最后明确要求的全量轮换：后台以独立映射记录专用 Key，每次撤销全部旧测试 Key，为现有分组重建，归当前操作管理员。普通 Key 和原账务记录不受删除操作影响。授权或订阅不足的组显示失败原因；数据库写入或随机数生成失败整批回滚。删除标记也采用独立加密随机值，避免与普通自定义 Key 撞名。界面不读取或提交密钥。

结果列表不包含过程和原始模型响应；SVG按需读取最终作品并在无脚本沙箱中预览，糖果只返回判定。完成时间/耗时来自真实执行，超时、截断、协议失败和输出过大不计成功。后台以数据库锁和租约限制并发，所有实例合计最多2个任务。总开关/配置或Key轮换的跨实例检测周期为5秒，已有上游请求的停止仍受既有网关取消传播边界约束。
