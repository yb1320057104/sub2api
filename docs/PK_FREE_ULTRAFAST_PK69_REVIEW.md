# pk.69 免费 Ultrafast 与 Fast 定价核对

本次按用户要求增加独立分组“免费 Ultrafast”，并核对强制 Fast 未开启免费时的计价。扩展 PK-004/042，沿用 PK-021/031；不创建新的重复功能入口。

## 使用方式与语义

- 分组管理的创建/编辑页面，在“OpenAI Fast / Ultrafast 模式”内开启“免费 Ultrafast”并保存。
- 如需主动请求 Ultrafast，同时开启已有“强制使用 Ultrafast”；免费开关本身只控制结算，不会改变请求档位。
- 如需普通 Fast，使用已有“强制使用 Fast（priority）”。“免费 Fast”只免 priority/fast 附加费，“免费 Ultrafast”只免 ultrafast 附加费。两项免费设置可同时开启。
- 免费是按相同请求的 Standard 价格重算客户费用，仍保留标准模型价、渠道覆盖、用户/分组/账号侧用户倍率、高峰、模型策略和长上下文规则；不是整次请求免费，也不减少上游额度消耗。
- 原始档位和加速档 TotalCost 保留，账号成本依照原有统计规则计算。缺少定价时保留既有零费用 usage 日志；其他计算错误仍返回错误。
- 强制档位仍受全局策略、模型及上游支持限制。已有 WebSocket 的强制策略修改需按原规则重新建立会话；不保证固定倍数提速。

## 实现与兼容

新增 `free_openai_ultrafast` / `FreeOpenAIUltrafast`，迁移343以 `IF NOT EXISTS` 追加 `BOOLEAN NOT NULL DEFAULT FALSE`；保留旧迁移和历史账单。管理员创建/编辑/复制、Ent、仓储投影、鉴权缓存及前端类型完整接入。鉴权缓存版本35升级36，旧快照重新加载；更新省略字段保留原值，显式false关闭，非OpenAI/Composite平台归一为false。

普通用户DTO保持原有权限边界。前端兼容旧响应缺字段为false；取消或重置表单不把上次开关带入下一次创建。新增列表徽标独立显示计费豁免，即使未打开强制档位也能看到保存的设置。

结算沿用 `openai_gateway_usage.go` 中免费 Fast 的同一标准价重算路径，在最终服务档位解析后分别判断两个开关。预约预估目前使用标准input/output价格，不按tier加价，本次不重复乘除档位倍率。现有利润准入比较配置倍率，未按真实上游tier费率重算；此次不扩大其功能范围，也不将平台 TotalCost 声称为外部上游实际账单。

## Fast 倍率结论

源码 `serviceTierCostMultiplier` 的普通 priority/fast 默认2倍，Ultrafast默认6倍。Sol/Astra模型策略维持Fast2倍，GPT-5.5保持原有2.5倍；显式渠道 `fast_multiplier` 优先。Fast 的显式档位单价与通用倍数不会重复叠加。

长上下文输出1.5倍是独立规则，不能据此判断 Fast 被设成1.5倍。分组等倍率也与档位倍率分开计算，例如标准价×Fast2×分组0.75，结果为标准价的1.5倍，但Fast本身仍为2倍。

本次未修改Fast定价算法或现有生产配置。增加包含旧1.5倍目录数据的Sol/Astra回归，并分别断言输入、输出、缓存和最终客户倍率，防止混淆长上下文或渠道覆盖规则。本文只记录公开源码语义与合成测试，不包含生产流量、账号、配置快照或部署身份。
