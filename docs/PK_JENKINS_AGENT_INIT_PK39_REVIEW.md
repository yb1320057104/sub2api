## 现场证据与判断边界

修复前只读进程检查发现 234 个僵尸进程：48 个 git、186 个 sh，均归属 Jenkins Agent Java，记录的退出码均为 0。Java 是容器 PID 1，运行配置未启用 init；Agent Dockerfile 的入口最终直接 exec Java。没有发现 Chrome/Chromium/Crashpad/Xvfb 残留进程。

上述证据确认 Agent 缺少专用的孤儿进程收养/回收层。无法仅凭已经退出的进程还原每个进程对应的具体历史构建或包装脚本，不宣称它们全部来自某次中断任务。init 用于收养并回收孤儿，不能代替仍存活父进程等待其普通子进程，也不承诺未来绝不再有任何僵尸。
