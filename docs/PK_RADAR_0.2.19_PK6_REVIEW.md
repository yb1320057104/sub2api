## 代码与边界

| 范围 | 静态核对依据 |
|---|---|
| 模型并行 | radar_account_runner.go 为每个模型启动执行；radar_account_parallel.go 各自重新取得并核对账号/母号身份，避免共享可变映射缓存。网络执行不受结果事务互斥锁串行限制。 |
| 并发预算 | 每实例最多8个账号，每账号最多8个模型，最多64个模型调用；单模型5分钟、整轮6分钟。租约仍为6分钟，每30秒续约。分组测试调度不变。 |
| 即时转组 | radar_account_early_move.go 原子提交首个失败模型、不合格判定、全部原分组替换及调度outbox；仍检查配置代次、租约、账号身份、原组快照和目标准入。后续模型看到已成功转组后只提交结果，不重复转组。 |
| 收尾与取消 | finishRadar 不再转组；读取并保留已提交的转组元数据。配置变化/取消/过期不能覆盖已提交的失败证据；新配置下仍通过代次隔离旧判定。取消前未提交的结果不能触发新转组。 |
| 错误详情 | 仅糖果分支提取结构化 message/detail、code、type、param，HTTP状态保留。在原生账号请求返回边界统一脱敏已知密钥、母号凭据、代理认证、授权头、Cookie和令牌后限制长度，不保存完整错误响应或推理。普通连通测试路径不变。 |
| 前端展示 | 雷达每个模型展示 error_message；原详情沿用相同字段。账号列表将模型/答案/手测/详情移出平台列；通过 failed_models 展示具体不合格模型，多模型空聚合答案不再误报未识别。 |
| 用量组件 | showActions 默认 true，只有雷达传 false；OpenAI卡片去掉查询/次数/重置等操作，账号管理原操作和被动用量加载保持。 |
| 权限 | AppSidebar 管理员区域含雷达菜单；/admin/radar 的 requiresAuth、requiresAdmin 都为 true；后端路由位于 adminAuth 路由组，处理器继续调用 accountCandyTestAdmin。普通用户不能通过直接访问页面或接口绕过。 |
| 数据 | 不新增迁移、不修改旧表结构、不回填历史错误。沿用五张雷达表及旧历史只读兼容。合法转组仍仅写既有 account_groups 与 scheduler_outbox。 |
| 出口 | 原生账号凭据、模型映射、协议、TLS、账号代理和出口探测路径保持；无代理才直连，代理失效不直连兜底。 |
