# pk.55 安全审计菜单与排行榜

基于私库 main `83270aaa593a6833b4e0c435a2f6bd95f0c3c3ae` / 已发布 pk.54。用户要求安全审计每个菜单只显示一种设置，取消锚点跳转和启停复选框，并保留用户耻辱排行榜。

## 页面行为

- 审计中心保留一个管理入口，页内分为通用设置、内容审计、关键词审计、提示词审计、风险分级、自动处罚与扣费、扣款诊断、审计记录。点击只切换当前面板，不滚动到长页面其他位置；支持键盘方向键、Home、End。
- 编辑面板保持挂载。内容与关键词复用唯一编辑器和同一份草稿，切换保留关键词、密钥编辑及其他未保存值；两个菜单直接展示共用检测开关和执行方式。底部继续统一提交带修订号的原子保存，不自动覆盖旧差异设置。
- 启停、分级、自动扣费、封禁、逐规则启用、区分大小写及排行榜自动刷新统一使用可访问的 Toggle 开关。分组、扫描器与事件多选保持复选框语义。
- 审计记录按需加载内容或提示词记录，不挂载第二套配置面板；内容记录不再启动运行状态轮询，提示词记录不加载运行概览和分组配置。独立管理页面的既有行为保留。
- 管理员和普通用户均保留独立 `/security-policy-ranking` 菜单，取消管理员强制跳回审计中心。普通用户继续调用公开脱敏榜接口，不请求管理设置、不显示私有身份及扣款操作；管理员保留原明细和手动预览／确认扣款。自动处罚表单只在审计中心编辑。
- 原 `/admin/risk-control`、`/admin/prompt-audit` 地址兼容定位对应菜单；旧中心查询参数和锚点可以解析为分类，不影响草稿。

扩展 PK-026/031/041/043，沿用 PK-021/027/046，无新增 ID。只有前端及交付文档变化，无后端、迁移、依赖、首字计时、费用计算或生产配置修改。pk.54 的最低额、分组倍率、用户归属、去重和下游追加费用规则保持。
