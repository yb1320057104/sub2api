## 权限管理密钥的交叉审查

- `adminaccess.RouteAllowed` 按方法和 Gin 完整路径精确匹配，未登记路径默认拒绝。币安充值/实时账单、排行榜扣费/自动禁用配置、分组智商测试、新账号糖果测试和 PK 系统写操作未被上游通用权限自动放行。
- 管理密钥生命周期只允许管理员 JWT，会沿用二次验证；旧全权密钥仍可使用，停止新建，仅允许轮换已有值或删除。此为上游授权体系更新，不是取消 PK 管理员权限。
- 受限账号新增/编辑/导入走专门字段校验及事务。普通编辑不接收任意 `extra`，不能隐式更改缓存转换或 Kilo 开关；Codex 重新导入在锁内合并当前 `Extra`，再经原 `UpdateAccount` 校验。完整管理员创建、编辑、批量 API 的原布尔/倍率校验及缺字段保留仍在。

- 管理密钥自身使用专用 `admin.api_key.request` 审计；因为 PK 路由未列入其授权目录，这一上游审计路径不成为 PK 新增免审入口。普通管理员 PK 路由仍经过原管理员认证、审计和合规门禁。

## PK-034 集成静态复核

账号测试以选定账号及其实际凭据母号的快照调用既有账号测试传输，未借分组调度随机选择其他账号。独立的服务、设置键、结果/租约表和管理员入口保持 PK-032 原分组测试不变。后台经过原激活门，Cleanup 先取消并等待本轮请求及结果收尾；重复停止只清理相同生命周期，不覆盖之后重新启动的服务。

- 管理接口额外校验完整管理员身份，明确拒绝受限管理密钥；输入不能提交凭据、上游 URL 或任意提示词。请求/响应大小有界，结果只保存最终助手文本与固定错误分类，不保存原始凭据、响应流或请求头。
- 同账号执行有本进程占位和数据库租约两层保护，配置更新与领取/完成共用事务锁。过期 running 清理独立于定时开关，因此手动测试即使在定时关闭时异常退出，租约到期后也能恢复。
- 事务前读取账号/凭据母号请求快照，领取时在账号、母号及代理行锁内以同一规范化 SHA256 核对身份，再保存原组集合；不在持有 SQL 事务时额外申请仓库连接，避免合法的单连接池配置等待自身。完成后复核代次、有效租约、账号身份和原组集合。凭据、模型映射、代理 ID/协议/地址/端口/凭据及已选协议/Kilo/TLS 字段变化会保守跳过转组，避免旧结果迁走已修改的账号。摘要及凭据快照不持久化、不返回 API；不宣称冻结全部外部服务状态。
- 只有取得协议完整的最终回复后才作 21 判定；网络/HTTP/截断/缺失终态为请求失败，不自动转组。账号专用 Responses 检查同时拒绝非空 incomplete_details、未完成 output 和工具/未知输出，Chat 拒绝工具/函数调用、非 stop 终态或缺失 DONE；不改变旧分组测试解析。完整但无法识别有效答案属于不合格。转组前持锁复查目标分组有效性、平台、OAuth 和隐私要求；不满足时保留现有分组并记录说明。
- 结果终态、删除旧关联、加入目标组和包含新旧组 ID 的调度 outbox 在同一事务提交。outbox 复用既有账号快照更新与分组重建流程，缓存更新仍具有原后台消费延迟，不描述成原子同步所有进程内缓存。
- 前端列表按 200 个账号分批读取，使用请求代次和取消控制防止旧读取覆盖新任务；新转组结果触发账号列表重载。详情文本使用 Vue 转义，配置说明覆盖手动/定时共用转组规则、请求失败不转组及目标组账号跳过定时检查。
- 配置 PUT 要求五个字段齐全，仅目标组可显式 null；缺失/非法类型/其他 null/未知字段拒绝，避免不完整请求意外停测或清空目标。结果模型与强度为配置请求快照，后续账号映射、OAuth 模型归一化及 Kilo 强度转换仍按原规则执行。
