基线为新私库 main `4d304732a3ddfc1fa89c6f4f91a74da6c6653afd`，正式 pk.43 为 `5ac76534d6aaad13914f0e3806a80ce52d99fcbc`。本轮不合并上游。用户要求增加批量切换 HTTP/HTTPS，并明确保留首字计时起点；最终只发布 GitHub，由用户手动切换版本，不部署生产。

## 功能与保护核对

- 新增 PK-040：原生代理列表勾选后选择 HTTP 或 HTTPS，确认窗口冻结 ID，最多500项去重正整数。仅原子更新协议与更新时间，地址、端口、凭据、状态、到期、直连设置和账号绑定保持；每条独立事务，部分成功明确反馈，失败项保留勾选。
- 同事务清除绑定账号的额度探测快照，为全部绑定账号写调度 outbox，避免缓存继续使用旧协议；代理延迟/质量 Redis 展示缓存尽力清理，失败不会撤销已提交的协议。批量操作不主动探测网络。
- 接口保持完整管理员边界，不新增受限管理密钥写权限。参数校验、审计事件和逐项固定安全错误齐全，不返回数据库/代理地址/认证错误原文。
- PK-025：普通 SOCKS5 保持支持；SOCKS5 或缺用户名/密码的 HTTP(S) 开启香港节点预探测时，返回明确提示。覆盖新代理、替换代理和已存代理开关切换；仅预探测类型错误可向外映射，其他错误继续脱敏。预探测协议仍需专用网关支持，币安全套 API 同出口及失败关闭保持。
- PK-007～012/037：本轮曾草拟的首字起点变更已全部撤销，六个网关文件与基线一致。未改变流式输出、计费、调度统计或历史记录；未做真实 SOCKS/HTTP 对照，不宣称协议切换一定降低首字。
- PK-001～006、013～024、026～036、038/039：业务无影响，沿用既有权限、加密、启动门、更新/回退及账务边界；PK-016/017/020/021沿用本机构建、同制品隔离验收和私库发布登记。PK-029/030保持已移除，不复用ID。
- 无新增依赖或迁移，不改历史数据、CF、更新凭据、加密密钥及生产代理。HTTP CONNECT可访问HTTPS目标；HTTPS代理指与代理本身建立TLS，同地址和端口必须由供应商支持。
