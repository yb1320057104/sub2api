## 功能与保护核对

- PK-022/024/025：只读现场确认运行 pk.44，币安连续失败5次形成16分钟退避，修改代理没有清理旧等待；当时无活动查询锁，泛化错误不能证明是币安真实限流。保存有效代理/凭据变化时，事务内只恢复已知非限流失败；同值保存、无关字段、未知遗留错误、活动查询与未来限流锁均不清除。
- 查收与账单将真实429/418的冷却保存在共享 API 锁中，并清空查询 token 区分“正在查询”和“限流等待”；旧版本固定限流错误及两类计划时间继续兼容。管理员渠道显示就绪、查询中、普通间隔、失败等待、真实限流及剩余时间，保留最近错误。倒计时只更新显示，到期允许手动查询，不自动请求币安；隐藏或卸载清理计时器。
- PK-034/035：雷达出口探测失败立即换路，不先向失败出口发送模型。按用户追加要求，真实网络请求/正文读取失败在同轮逐个尝试空闲代理，不再固定最多3个出口；保留原整轮6分钟、单模型5分钟预算。完整答案不重测，明确 HTTP 业务错误、格式错误和取消不盲目重试；池耗尽明确结束，不直连兜底。
- 候选来自原生 IP 池，必须有效、未过期且没有任何非删除账号绑定，包括停用账号仍占用。专属数据库连接上的 advisory lock 排除其他重试任务；选取、发送前和最终绑定核对身份及空闲，手工配置变动不被覆盖，无跨网络长事务。同账号多模型共用出口会话，账号并发仍3。
- 备用通过出口探测且取得完整模型响应后才可绑定，答案是否21不影响网络可用性判断。整轮末沿用原租约/身份/分组保护，在原分组事务之后绑定已验证备用、清理旧额度探测快照并写调度 outbox；取消和人工变更不绑定。原首个完整错答提前转组及合格多目标保持。
- PK-036：授权测智的备用候选同样限定空闲且排他，保持原最多3出口及仅发送前网络失败重试，不持久更改授权账号的代理；登录、CF、凭据加密、授权开关和分组规则保持。
