# PK 完整部署包

本包包含同次 Jenkins 构建、验收和封存的私有应用镜像；Chromium、字体及浏览器运行库已经在镜像内，默认路径和容器运行参数已配置。部署时不会安装主机软件包或下载浏览器。

## 新部署

环境要求为 Linux amd64、Docker 和 Docker Compose v2。解压后执行：

    sh install.sh /你的部署目录

目标目录必须为空。脚本校验 SHA256、导入随包镜像，自动生成数据库密码、Redis 密码、JWT 密钥、固定 TOTP_ENCRYPTION_KEY 和初始管理员密码，并启动服务。数据库及 Redis 的标准镜像在首次启动时由 Docker 拉取；无需单独安装 Chromium、配置浏览器路径或登录私有镜像仓库。

默认仅监听 127.0.0.1:8080，可按部署环境配置反向代理。初始管理员邮箱为 admin@example.com，密码及其他持久化秘密保存在部署目录的 .env 文件中，权限为0600。请和 data、postgres_data、redis_data 一起备份；不要重新生成已有加密密钥。

## 已有部署

    sh install.sh --load-only

此命令只校验并导入本包的应用镜像，不修改运行中的容器、配置或数据。随后将原 Compose 项目的应用 image 改为 image.txt 中的固定版本，保留原 project、配置、所有环境变量、端口和数据挂载，再按维护窗口或既有平滑切换流程更新应用容器。不要对已有目录运行全新部署初始化。

网页更新包只替换二进制。旧镜像首次启用授权浏览器时，必须使用本完整部署包中的应用镜像更新容器；无需另行安装浏览器。后续新部署直接使用本包即可。

账号密码、2FA和授权代理仍由管理员在工作台录入，本包不预置任何账号或代理凭据。
